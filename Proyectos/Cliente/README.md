# Buscaminas

1. Primero ejecute "npm install" para instalar las dependencias necesarias.

2. Asegurese de tener el servidor corriendo en local para que funcione. (en caso de hacerlo con la API online, habrá que cambiar las rutas en GameBoard.jsx y en HomePage.jsx).

3. Después con "yarn dev" podrá jugar directamente, también puede usar los comandos "yarn build" y "yarn preview".
